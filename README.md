A make.fun entry for the **Two Days of Quiet Dread** bounty: a program that writes
one code review comment — a single line of at most 140 characters that approves a
pull request while carrying quiet existential dread.

## The entry

> Approved. This code will outlive us all, and I have made my peace with that.

## How it works

`main.py` writes the comment to `/output/entry.txt` (76 characters, one line, UTF-8).
